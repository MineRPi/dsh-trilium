# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-16

### Added

- 20 `trilium_*` agent tools: notes CRUD/undelete/clone, search, attributes,
  attachments, calendar notes, revisions, backup/export/import, history,
  memory remember/recall, and the weekly-report workflow.
- Live memory index auto-injected at session start (toggleable).
- Standalone settings card (设置 → 插件 → 可配置) with connection test.
- Config store at `~/.dsh/dsh-trilium.json` (0600, atomic write).
- System-prompt announcement with the memory rules.
- Bilingual README (English + 中文).
